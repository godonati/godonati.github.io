03 · Personal product exploration

AI file organizer

A product concept for turning a messy folder into a trusted, reviewable system—without hiding the decisions the user needs to understand.

AI

The problem

Automation is only useful when people can trust it.

File organization is a personal pain point with a visible before-and-after: files are hard to find, categories are inconsistent, and automatic changes can feel risky. This project is an opportunity to practice discovery, classification, evaluation, and human-in-the-loop design.
