Can AI organize messy files without hiding its decisions?

A prototype for turning an overwhelming folder into a trusted, reviewable system—one that explains what it sees before it changes anything.

AI

The problem

Automation is only useful when people can trust it.

I started this project from a personal need: files are hard to find, categories are inconsistent, and automatic changes can feel risky. The prototype reads metadata, folder hierarchies, and AI-generated descriptions to understand what a file might be before organizing it.

The prototype

Make the system’s thinking visible.

The current version can read files, combine metadata and folder context with AI descriptions, and surface a proposed understanding. The organization step is still being built. That boundary is intentional: the product should earn the right to move files by showing its reasoning first.

What I’m learning

The hard part is not calling the model. It is designing the recovery path.

As the prototype grew, speed became a product requirement. Large batches are still sluggish, and the next work is to make processing faster while keeping the experience understandable. I’m also exploring how one guided flow could help a first-time user recover when a file is ambiguous or a setting changes.

Status

Early, useful, and still becoming evidence.

This project has not yet been tested with other users. The next milestone is a small evaluation set using real files, a speed benchmark, and a few conversations with people who regularly manage large or messy folders.
